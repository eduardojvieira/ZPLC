**Date**: 2026-11-25  
**Requirement**: JRN-001, with the counting rule of JRN-003  
**Source of truth**: the documentation site as it is today (`docs/docs/**`, English). The product text was read only to mark a step WRONG.

## How to read this file

Each journey runs from a clean install to an outcome a person can see. Each step has the action, what the person sees, and where the documentation gives it.

| Mark    | Meaning                                                                                                          |
| ------- | ---------------------------------------------------------------------------------------------------------------- |
| ok      | A page and section give the step.                                                                                |
| GAP     | The documentation does not give the step, or gives it only in part. The cell says what is missing.               |
| WRONG   | The documentation gives the step, and it differs from the product text or from another page. The cell says how.  |
| PERSON  | A physical operation (rule 8 of `AGENTS.md`): a person does it, never an agent. It carries one of the marks too. |

A gap stays a gap. This file gives no instruction of its own. Paths are relative to `docs/docs/`.

## The five largest gaps

1. No page tells a person how to set up the assistant: where the provider and the key are entered, which providers exist, and what the person sees (journey 4, steps 4 to 7).
2. The MCP server has no tool or resource that writes a program, reads the plant or the goal, or connects from the application, so journey 5 cannot be followed as written (steps 5, 9, 10, 11).
3. Plant I/O mode, the only way a board drives the plant, is documented as a disabled command with no scene to use, so journey 2 stops before its outcome (steps 9, 11, 13).
4. The path to the first plant lesson is not counted: the docs give a prerequisite per lesson and no total, so journey 1 has no time target (steps 11, 12).
5. A teacher cannot do the work of journey 3 from a clean install: the outline and the check need a checkout and Bun, and the import of progress is one sentence (steps 5, 10, 11).
