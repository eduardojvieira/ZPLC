# Security policy

Please report suspected vulnerabilities through this repository's **GitHub
Private Security Advisories** channel. Do not include exploit details, secrets,
or device identifiers in public issues.

Include the affected revision, a minimal reproduction, impact, and any safe
mitigation you identified. Reports involving bytecode loading, persistence,
Electron IPC, device control, credentials, or unsafe output states should say
so explicitly.

ZPLC does not make certification, response-time, or support-SLA claims in this
repository. A report is assessed against the supported evidence and release
scope for the affected revision.
