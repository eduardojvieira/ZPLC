# Instruction List: the current result in a two-hand control

Read an Instruction List program as one current result that each line combines with an operand, and use it to enable a press only when both hands are on the buttons and the guard is closed.

## Objectives

- Read an Instruction List (IL) program as one current result that each instruction combines with an operand, from top to bottom.
- Use LD, LDN, AND, XOR and ST to turn three inputs into three outputs.
