# A sequence in Sequential Function Chart: fill, then mix

Complete a Sequential Function Chart with three steps by adding the missing timed transition, and check that the valve and the mixer never run together.

## Facts

- Module: [5](../modules/module-5.md)

- Estimated time: 25 minutes
- Languages: SFC

- Prerequisites: [edge-counter-pulses](./edge-counter-pulses.md)

## Objectives

- Read a Sequential Function Chart as steps that are active one at a time, actions that run while their step is active, and transitions that move the activity.
- Add a timed transition that uses the elapsed time of a step.

## What the evidence covers

Tests provide native POSIX host evidence with one 10 ms task; they do not establish process volumes, mixing quality, valve timing on real equipment, HIL, or certification.
