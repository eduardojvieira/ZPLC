# Send each colour to its belt

Read the colour of each workpiece that waits at the stop blade, push the red ones onto the side belt and let the blue ones ride on.

## On a board

The lesson needs an infeed belt, a colour sensor, a pusher and two bins; a learner board has none of them, and the scene supplies all four. Complete it in Simulation, where the scene and its items are part of the scenario.
