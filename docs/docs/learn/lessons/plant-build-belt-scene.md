# Build a belt scene from the empty floor

Open the Scene editor on an empty floor, place a belt, an emitter, a sensor and a start button with the names the lesson gives, bind their signals in the plant map and write the program that runs on them.

## Facts

## Objectives

- Place the parts of a scene by name and bind each signal of the plant map to a program variable.
- Run a program on the scene you built and see the Check grade that scene, not a copy of it.

Tests give deterministic native POSIX host evidence on a simulated plant scene; they are not physical, hardware, HIL, or certification evidence.

## On a board

The lesson is about placing parts and binding signals in the Scene editor; a learner board has no scene to edit, and the editor only exists in Simulation. Complete it in Simulation, where the scene editor and the scene are part of the lesson.
