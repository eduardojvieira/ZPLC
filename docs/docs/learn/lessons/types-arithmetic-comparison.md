# Types, arithmetic and comparison: a total and three bands

{/* >>> GENERATED (tools/docs/generate_course_pages.ts): learn/lessons/types-arithmetic-comparison. Do not edit. >>> */}

Keep a running total in an INT variable, add to it on each press, and turn it into three BOOL results with comparison operators.

## Facts

- Module: [4](../modules/module-4.md)
- Level: Intermediate
- Estimated time: 20 minutes
- Languages: ST

## Objectives

- Use an INT variable for a number and a BOOL variable for a yes or no, and see that a comparison turns a number into a BOOL.
- Add to a number only on the rising edge of an input, so that a button held for several scans counts once.
