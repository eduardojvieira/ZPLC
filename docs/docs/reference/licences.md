## Third-party packages and firmware dependencies

- **Desktop application packages and fonts.** At packaging time, `scripts/release/licenses.ts` generates `THIRD-PARTY-NOTICES.txt` from `bun.lock`, the installed packages, and `scripts/release/font-licences.json`, and `electron-builder.yml` ships that file inside every installer. `scripts/release/sbom.ts` generates the CycloneDX software bill of materials. The final `THIRD-PARTY-NOTICES.txt` and SBOM files for a release are generated when that release is cut.
- **Embedded firmware dependencies.** Zephyr RTOS (`Apache-2.0`, pinned in `west.yml`) and FreeRTOS-Kernel (`MIT`, pinned in `firmware/lib/zplc_core/src/hal/freertos/freertos.cmake`) are fetched at firmware build time and are not vendored in this repository.
