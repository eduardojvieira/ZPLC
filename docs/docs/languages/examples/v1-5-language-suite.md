# Compatibility Language Examples

This historical v1.5 language suite is retained as compatibility evidence. It
does not establish current universal language parity, target behavior, or HIL.

## Shared example intent

The examples express a small timer/output control objective in ST, IL, LD, FBD,
and SFC forms. Each form must be compiled and tested through its current editor
and compiler path before being used as evidence.

## Scope

- ST is the primary current language-service path.
- LD, FBD, and SFC use semantic visual models and generated ST artifacts.
- IL remains a compatibility path only where accepted by the compiler.
