# Reunir piezas en un cajón

Lleve un cajón a un elevador, alimente cinco piezas dentro de él una por una y envíelo lleno.

## Objetivos

- Combinar un conteo, un elevador y un cajón en una sola secuencia de pasos.
- Mover el elevador solo con su superficie detenida y alimentar la pieza siguiente solo después de que la anterior haya aterrizado.
