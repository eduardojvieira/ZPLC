Encienda una bomba de lubricación durante un tiempo fijo con una pulsación, por mucho que se mantenga el pulsador y haga lo que haga el resguardo después.

## Objetivos

- Encienda una salida durante un tiempo fijo con una pulsación, por mucho que se mantenga pulsado el pulsador.
- Haga que una pulsación inicie un pulso solo cuando se cumple una segunda condición, y que un pulso ya iniciado llegue hasta su final.
