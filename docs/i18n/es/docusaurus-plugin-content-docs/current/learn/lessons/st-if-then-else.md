# Elegir uno de tres estados con IF, ELSIF y ELSE

Muestre el estado de un tanque en tres lámparas con una sola instrucción IF, de modo que haya exactamente una lámpara encendida en todo momento.

## Objetivos

- Escriba una instrucción IF con ramas ELSIF y ELSE que elija un estado entre tres.
- Haga que exactamente una de tres salidas esté encendida en todo momento, sea cual sea el nivel anterior.
