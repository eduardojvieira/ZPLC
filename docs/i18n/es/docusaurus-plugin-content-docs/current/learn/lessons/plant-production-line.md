# Equilibrar una línea de producción

{/* >>> GENERATED (tools/docs/generate_course_pages.ts): learn/lessons/plant-production-line. Do not edit. >>> */}

Divida una línea en un bloque de función por máquina y envíe piezas alternas a cada una para que ambas máquinas hagan cuatro productos.

## Datos

- Módulo: [17](../modules/module-17.md)
- Nivel: Avanzado
- Tiempo estimado: 50 minutos
- Lenguajes: ST
- Rutas: Simulación
- Página de lectura: no
- Planta: [Línea de producción balanceada](../../plant/scenes/balanced-production-line.md)
- Requisitos previos: [function-block-pump-pair](./function-block-pump-pair.md), [plant-lift-stacking](./plant-lift-stacking.md)

## Objetivos

- Mover el control de una máquina a un bloque de función y usar una instancia para cada máquina.
- Equilibrar dos máquinas de distinta velocidad alternando las piezas entre ellas.

## Etapas

1. **Objetivo**
2. **Predecir**
3. **Editar**
4. **Ejecutar**
5. **Observar**
6. **Reflexionar**

## Qué cubre la evidencia

Aprobar significa que su programa se comportó correctamente en el simulador de esta computadora. No dice nada sobre una máquina real, sus tiempos ni su seguridad.

## En una placa

La línea necesita dos centros de mecanizado de distinta velocidad y un brazo desviador; una placa del estudiante no tiene ninguno, y la escena los aporta. Complétela en Simulación, donde la escena y sus cajas forman parte del escenario.
