# Variables, tipos y direcciones en escalera: bits de memoria, valores TIME y el mapa de E/S

Guarde una solicitud en un bit de memoria, almacene una duración en una variable TIME y vea qué variables están conectadas a la máquina mediante el mapa de E/S.

- Módulo: [4](../modules/module-4.md)
- Nivel: Intermedio
- Tiempo estimado: 20 minutos
- Lenguajes: LD
- Rutas: Simulación

## Objetivos

- Distinga un bit de memoria de una variable conectada a una entrada o salida física mediante su dirección.
- Elija el tipo que corresponde a un valor (BOOL, INT, REAL, TIME) y fije el valor de una variable TIME.

## Qué cubre la evidencia

Las pruebas aportan evidencia del host con el runtime nativo POSIX y una tarea de 10 ms; no demuestran el cableado, los niveles eléctricos ni los tiempos de entradas y salidas reales, HIL ni certificación.
