Distinga tres alturas de caja con dos barreras, recuerde la respuesta hasta que la caja llegue a la transferencia de cadenas y envíela de frente, a la derecha o a la izquierda.

## Objetivos

- Decidir una ruta a partir de una combinación de dos sensores.
- Recordar una decisión mientras la caja siguiente ya pasa por los sensores.
