# Escriba un parpadeador en texto estructurado

{/* >>> GENERATED (tools/docs/generate_course_pages.ts): learn/lessons/blink-structured-text. Do not edit. >>> */}

Construya un parpadeador con un temporizador TON y una variable de memoria, y haga que funcione solo mientras una entrada de habilitación está en ON.

## Datos

- Módulo: [1](../modules/module-1.md)
- Nivel: Fundamentos
- Tiempo estimado: 15 minutos
- Lenguajes: ST
- Rutas: Simulación, Hardware
- Planta: ninguna
- Requisitos previos: [scan-cycle-one-scan-memory](./scan-cycle-one-scan-memory.md)

## Objetivos

- Escriba el patrón de temporizador y memoria que hace cambiar una salida a intervalos fijos.
- Condicione una salida a una entrada para que se detenga de inmediato cuando la entrada cae.

## Etapas

1. **Objetivo**
2. **Prediga**
3. **Edite**
4. **Ejecute**
5. **Observe**
6. **Reflexione**

## Qué cubre la evidencia

Las pruebas aportan evidencia del host con el runtime nativo POSIX y una tarea de 10 ms; no son evidencia de una lámpara física, de los tiempos del hardware, de HIL ni de certificación.
