# Almacenar y recuperar

{/* >>> GENERATED (tools/docs/generate_course_pages.ts): learn/lessons/plant-warehouse. Do not edit. >>> */}

Maneje un transelevador desde un diagrama: almacene cada caja en la primera celda libre y traiga una caja de vuelta cuando se pulse su botón de petición.

## Datos

- Módulo: [17](../modules/module-17.md)
- Nivel: Avanzado
- Tiempo estimado: 60 minutos
- Lenguajes: SFC
- Rutas: Simulación
- Página de lectura: no
- Planta: ninguna
- Requisitos previos: [plant-three-level-lifts](./plant-three-level-lifts.md)

## Objetivos

- Escribir las secuencias de almacenar y de recuperar de un transelevador como cadenas de pasos.
- Llevar una tabla de celdas ocupadas y las peticiones que esperan, y elegir el trabajo siguiente a partir de ellas.

## Etapas

1. **Objetivo**
2. **Predecir**
3. **Editar**
4. **Ejecutar**
5. **Observar**
6. **Reflexionar**

## Qué cubre la evidencia

Las pruebas dan evidencia determinista del host POSIX nativo sobre una escena de planta simulada; no son evidencia física, de hardware, HIL ni de certificación.

## En una placa

El diagrama mueve un transelevador a lo largo de una estantería; una placa del estudiante no tiene transelevador ni estantería, y la escena aporta ambos. Complétela en Simulación, donde la escena y sus cajas forman parte del escenario.
