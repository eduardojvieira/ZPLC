# Bloques de comparación y de cálculo en escalera: una alarma de tanque y una división segura

{/* >>> GENERATED (tools/docs/generate_course_pages.ts): learn/lessons/ld-compare-math. Do not edit. >>> */}

Use bloques de comparación como condiciones y bloques matemáticos como cálculos en escalera, y proteja una división para que un divisor en cero nunca llegue a ella.

## Datos

- Módulo: [4](../modules/module-4.md)
- Nivel: Intermedio
- Tiempo estimado: 25 minutos
- Lenguajes: LD
- Rutas: Simulación
- Planta: ninguna
- Requisitos previos: [ld-variables-and-types](./ld-variables-and-types.md)

## Objetivos

- Use un bloque de comparación como condición en serie y elija entre GT y GE para un límite.
- Calcule con bloques matemáticos que se ejecutan solo mientras su peldaño tiene energía, y proteja una división con una comparación NE para que el divisor nunca sea cero.
