# Clasificar por código de identidad

{/* >>> GENERATED (tools/docs/generate_course_pages.ts): learn/lessons/plant-vision-sorting. Do not edit. >>> */}

Lea el código de cada pieza que ve el sensor de visión y accione un brazo desviador para que las piezas de código 2 salgan por la banda lateral.

## Datos

- Módulo: [16](../modules/module-16.md)
- Nivel: Avanzado
- Tiempo estimado: 50 minutos
- Lenguajes: ST
- Rutas: Simulación
- Página de lectura: no
- Planta: ninguna
- Requisitos previos: [plant-colour-separation](./plant-colour-separation.md)

## Objetivos

- Encaminar piezas por un código entero y no por un interruptor.
- Sincronizar un actuador con el recorrido de una pieza ya leída.

## Etapas

1. **Objetivo**
2. **Predecir**
3. **Editar**
4. **Ejecutar**
5. **Observar**
6. **Reflexionar**

## Qué cubre la evidencia

Las pruebas dan evidencia determinista del host POSIX nativo sobre una escena de planta simulada; no son evidencia física, de hardware, HIL ni de certificación.

## En una placa

La lección necesita un sensor de visión que lea códigos de pieza, un brazo desviador y dos bandas de producto; una placa del estudiante no tiene cámara ni piezas con código, y la escena aporta ambas. Complétela en Simulación, donde la escena y sus piezas forman parte del escenario.
