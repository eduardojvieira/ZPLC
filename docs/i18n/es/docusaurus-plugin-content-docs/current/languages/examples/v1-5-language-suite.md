# Ejemplos de lenguaje de compatibilidad

Esta suite histórica de lenguajes de la versión 1.5 se conserva como evidencia de
compatibilidad. No establece una paridad actual entre todos los lenguajes
ni el comportamiento en una placa ni el HIL.

## Intención compartida del ejemplo

Los ejemplos expresan un objetivo pequeño de control de un temporizador y una salida en ST,
IL, LD, FBD y SFC. Cada forma debe compilarse y probarse con el editor y el compilador
actuales antes de usarse como evidencia.

## Alcance

- ST es la vía principal de servicio de lenguaje en la actualidad.
- LD, FBD y SFC usan modelos visuales semánticos y artefactos ST generados.
- IL sigue siendo solo una vía de compatibilidad donde el compilador la acepta.
