# Ejemplos de lenguaje de compatibilidad

Esta suite de lenguajes histórica v1.5 se conserva como evidencia de
compatibilidad. No establece paridad universal actual de lenguajes,
comportamiento target ni HIL.

## Intención compartida del ejemplo

Los ejemplos expresan un objetivo pequeño de control timer/salida en formas ST,
IL, LD, FBD y SFC. Cada forma debe compilarse y testearse mediante su camino
actual de editor y compilador antes de usarse como evidencia.

## Alcance

- ST es el camino actual principal de servicio de lenguaje.
- LD, FBD y SFC usan modelos visuales semánticos y artefactos ST generados.
- IL sigue siendo sólo un camino de compatibilidad donde el compilador lo acepta.
